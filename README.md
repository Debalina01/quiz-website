# Simple Quiz Website

This is a simple quiz website made using HTML, CSS and JavaScript.

## Features

* User ID entry and verification
* Multiple choice quiz
* Next and Previous buttons
* Selected answers are saved while moving between questions
* Quiz submission
* Score calculation
* Result page

## Website Flow

**User ID → Start Quiz → Answer Questions → Submit → Result**

## Technologies Used

* HTML
* CSS
* JavaScript

## How to Run

1. Open the project folder in VS Code.
2. Open `index.html` using Live Server.
3. Enter a valid User ID.
4. Start the quiz and answer the questions.
5. Submit the quiz to see the result.
